# Pixelium Player Android — pilote Olivier

Player Android plein écran pour MXQ Pro / Android 10. Il s'associe avec un jeton à usage restreint créé dans le cockpit, envoie un heartbeat toutes les 30 secondes, télécharge les médias dans un cache privé et conserve la dernière playlist valide hors connexion.

Profil pilote recommandé : MP4, H.264, 1920×1080, 30 fps, AAC. APK debug réservé au test sur moniteur puis Colorlight X2M.
